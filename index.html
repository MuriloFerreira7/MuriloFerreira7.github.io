Como funciona

O que este site está fazendo?

1

JavaScript faz a requisição

A função fetch() envia uma requisição GET para a Jikan.

2

A API responde em JSON

A resposta contém título, nota, imagem, episódios, sinopse e outros dados.

3

O site monta os cards

O JavaScript percorre os dados e coloca as informações dentro do HTML.
